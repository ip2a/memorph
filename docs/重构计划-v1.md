# memorph 架构重构计划 v1

> **本文是验收标准。** 配套《架构文档-重要架构设计v1.md》《项目骨架设计v1.md》。
> 目标:把 memorph 从"单 crate(lib+bin 合一)"重构为规范的 workspace(核心 lib + CLI + 桌面壳),符合《架构文档 v1》的分层模型。
>
> **执行原则**:渐进迁移,每个里程碑独立 commit + 验证;**不留 Helper / Adapter / 兼容 re-export / shim / 回退补丁**;业务行为零回归。

## 2. 现状(调研结论)

- 单 crate `memorph`,lib + bin 合一,**src 约 11.2 万行**
- workspace 根已存在:`rust/Cargo.toml`,`members = ["crates/*"]`
- 应用层依赖集中在:`api/`、`server.rs`、`tui/`、`web.rs`、`web_assets.rs`、`cli.rs`、`bin/`、`hooks/server.rs`、`skills/server.rs`
- **核心生产代码干净**;唯一核心层对应用 router 的引用是 `providers/gemini/mod.rs` 的一个 `#[cfg(test)]`(通过 `crate::api::router().oneshot()` 做 API 端到端测试)→ M3 归位
- 外部 `memorph::` 消费者只有 **2 处**:`rust/crates/memorph/tests/compression_cli.rs`、`desktop/tauri/src/lib.rs`
- `build.rs` 内嵌 `apps/web/dist`(优先)或 `assets/web`(回退);`web_assets.rs` 全 axum

## 3. 目标架构

```
rust/
├── Cargo.toml                 # workspace: members = ["crates/*", "apps/*"]
├── crates/memorph/            # ★ 核心 lib(发 crates.io)
│   ├── Cargo.toml             # 无 axum/ratatui/clap/crossterm/tower_http/open
│   ├── assets/i18n.json       # 核心数据
│   └── src/                   # 领域逻辑 + IO
└── apps/memorph-cli/          # CLI(publish = false)
    ├── Cargo.toml             # 依赖 memorph + axum/ratatui/clap/...
    ├── build.rs               # 内嵌 web assets
    ├── assets/web/            # web dist 回退位置
    └── src/
        ├── lib.rs             # pub mod 应用模块
        ├── bin/               # memorph.rs, memo.rs
        ├── cli.rs, server.rs, api/, web.rs, web_assets.rs, tui/
        └── (hooks server / skills server 归位处)

desktop/tauri/                 # 壳(保持独立,不进 rust workspace)
└── 依赖 memorph-cli(path)
```

## 6. use 路径调整规则(关键)

模块移动后,引用路径按以下规则调整:

- **核心 crate 内部**:`crate::xxx` **不变**(都在核心)
- **CLI 应用模块互引用**:`crate::api`、`crate::server` **不变**(同在 CLI lib)
- **CLI 引用核心模块**:`crate::core` → `memorph::core`,`crate::canonical` → `memorph::canonical`,以此类推

核心模块集合(CLI 里 `crate::X` → `memorph::X`):
> `canonical`、`provider`、`providers`、`core`、`storage`、`format`、`cache`、`sync`、`session_projection`、`stats_dashboard`、`agent_environment`、`agent_management`、`provider_settings`、`config`、`logging`、`i18n`、`utils`、`hooks`(非 server)、`skills`(非 server)

CLI crate 名为 `memorph-cli`,lib 名默认 `memorph_cli`;bin 通过 `use memorph_cli::{...}` + `use memorph::{...}` 访问。
